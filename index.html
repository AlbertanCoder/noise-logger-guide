Print files

⚠ Don't print yet. Do Build step 3 first: measure the real Pi, power plug and mic. Then print the case base on its own (about 40 g of plastic) and set the bare Pi in it. If it drops in without force and sits flat on all 4 posts, print the lid. Print the mic holder last: its seat is a guess (45 mm) until the mic is measured.

Settings: PLA or PETG · 0.2 mm layers · 20% infill · 3 walls · no supports (the printer's own PLA profile is fine). Each file already lies the right way up: don't turn it. At a library, ask first: bed size (the largest part is 101 × 71 mm), time limit and cost.

How accurate? The 4 screw holes in the case measure 58.00 × 49.00 mm apart, the same as the official Raspberry Pi drawing. Every socket has at least 1.5 mm to spare on each side and the board drops straight in (all checked by script on the print files themselves). The drawing calls its own sizes approximate, so the first print is still a test.
